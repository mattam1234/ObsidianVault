# 📚 ObsidianVault

A well-organized personal knowledge management system built with [Obsidian](https://obsidian.md).

## 🎯 Overview

This vault provides a structured framework for capturing, organizing, and connecting knowledge. It follows best practices for personal knowledge management (PKM) and implements a proven organizational structure.

## 📂 Structure

```
ObsidianVault/
├── 00-Meta/          # Vault guides and documentation
│   ├── Home.md       # Main navigation hub
│   └── Vault Guide.md
├── 01-Inbox/         # Quick capture area
│   └── Inbox.md
├── 02-Projects/      # Active projects
│   └── Projects Index.md
├── 03-Resources/     # Learning materials and references
│   └── Resources Index.md
├── 04-Archive/       # Completed or inactive content
│   └── Archive Index.md
├── Templates/        # Note templates
│   ├── Note Template.md
│   ├── Project Template.md
│   └── Meeting Template.md
├── Attachments/      # Images and files
└── .obsidian/        # Obsidian configuration
```

## 🚀 Getting Started

### Prerequisites
- Download and install [Obsidian](https://obsidian.md)

### Setup
1. Clone this repository:
   ```bash
   git clone https://github.com/mattam1234/ObsidianVault.git
   ```

2. Open Obsidian and select "Open folder as vault"

3. Navigate to the cloned repository directory

4. Start with the [[00-Meta/Home|Home]] note for navigation

### First Steps
1. Read the [[00-Meta/Vault Guide|Vault Guide]] to understand the structure
2. Check out the [[Templates/Note Template|Templates]] for creating new notes
3. Start capturing ideas in the [[01-Inbox/Inbox|Inbox]]
4. Explore the sample content in [[03-Resources/Resources Index|Resources]]

## 📖 Key Concepts

### Inbox Processing
The [[01-Inbox/Inbox|Inbox]] is your quick capture area. Review it regularly and move notes to appropriate folders.

### Linking
Create connections between notes using `[[Note Name]]` syntax. This builds your personal knowledge graph.

### Tags
Use tags like `#project`, `#meeting`, `#resource` to categorize notes across folders.

### Templates
Use `Cmd/Ctrl + P` and search for "Templates" to insert a template into your note.

## 🔧 Workflow

1. **Capture**: Add new ideas to the Inbox
2. **Process**: Review inbox regularly, add context and links
3. **Organize**: Move processed notes to appropriate folders
4. **Connect**: Link related notes together
5. **Review**: Regularly review and refine your notes

## 📝 Note Types

- **Index Notes**: Navigation and overview pages
- **Project Notes**: Active projects and goals
- **Resource Notes**: Learning materials and references
- **Meeting Notes**: Meeting documentation
- **Standard Notes**: General knowledge and ideas

## 🎨 Customization
