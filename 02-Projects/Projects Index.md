## Guidelines

### Starting a New Project
1. Create a new note using the Project Template
2. Define clear objectives and timeline
3. Break down into actionable tasks
4. Link to related resources
5. Add to this index

### Project Workflow
- **Active**: Working on it now
- **Planned**: Will start soon
- **On Hold**: Paused but not cancelled
- **Completed**: Move to [[../04-Archive/Archive Index|Archive]]

### Best Practices
- Review projects weekly
- Update status regularly
- Keep tasks actionable
- Link related notes and resources
