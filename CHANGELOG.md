### Philosophy

This vault implements:
- **PARA Method**: Projects, Areas, Resources, Archives organization
- **Zettelkasten Principles**: Atomic notes and liberal linking
- **Progressive Summarization**: Layered understanding
- **MOC (Map of Content)**: Index pages for navigation
- **Inbox Processing**: Capture-first, organize-later workflow

### Resources Coverage

The vault includes comprehensive guides on:
- Obsidian basics and features
- Markdown syntax
- Note-taking strategies
- Personal knowledge management
- Keyboard shortcuts
- Plugin ecosystem
- Linking techniques
- Tags and metadata

### Quick Start

1. Install Obsidian
2. Clone this repository
3. Open as vault in Obsidian
4. Start with 00-Meta/Home.md
5. Read Vault Guide for full documentation
