# 📥 Inbox

## Purpose
This is your quick capture area. Drop any ideas, thoughts, or notes here without worrying about organization.

## Guidelines
- **Capture Fast**: Don't overthink where it belongs
- **Process Regularly**: Review daily or weekly
- **Move Forward**: Organize processed notes into appropriate folders
- **Keep Clean**: This should be temporary storage

## Processing Workflow
1. Read through each note
2. Add context if needed
3. Add appropriate tags
4. Move to correct folder or link to existing notes
5. Delete if no longer relevant

## Quick Capture Template
Use `Cmd/Ctrl + N` to create a new note here, then move it when processed.
