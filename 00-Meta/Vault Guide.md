# 📖 Vault Guide

Welcome to your personal knowledge management system! This guide will help you make the most of your Obsidian vault.

## 🎯 Purpose

This vault is designed to help you:
- **Capture** ideas and information quickly
- **Organize** knowledge in a structured way
- **Connect** related concepts through links
- **Review** and refine your understanding over time

## 📂 Folder Structure

### 00-Meta
**Purpose**: Vault documentation, guides, and meta-information
- Home page and navigation
- Guides and best practices
- Vault maintenance notes

### 01-Inbox
**Purpose**: Quick capture area for new ideas
- Drop notes here without worrying about organization
- Process regularly (daily or weekly)
- Move processed notes to appropriate folders

### 02-Projects
**Purpose**: Active projects and goals
- Current projects and initiatives
- Project plans and tracking
- Use project template for consistency

### 03-Resources
**Purpose**: Reference materials and learning content
- Articles, books, and course notes
- How-to guides and tutorials
- Organized by topic/category

### 04-Archive
**Purpose**: Completed or inactive content
- Finished projects
- Outdated information
- Keep for historical reference

### Templates
**Purpose**: Reusable note structures
- Note templates for common types
- Maintain consistency across notes

### Attachments
**Purpose**: Images, PDFs, and other files
- Automatically stores media files
- Keeps vault organized

## 🔗 Linking Best Practices

1. **Link Liberally**: Connect related notes
2. **Use Descriptive Names**: Make links self-explanatory
3. **Bidirectional Links**: Utilize backlinks feature
4. **Create MOCs**: Map of Contents for complex topics

## 🏷️ Tagging Strategy

- Use tags for categorization
- Keep tag hierarchy simple
- Common tags: `#project`, `#meeting`, `#resource`, `#todo`
- Add custom tags as needed

## ✨ Workflow Suggestions

### Daily Workflow
1. Review [[01-Inbox/Inbox|Inbox]]
2. Process new notes
3. Update active projects
4. Create connections between notes

### Weekly Review
1. Clean up inbox
2. Update project status
3. Archive completed items
4. Plan upcoming work

### Monthly Reflection
1. Review progress on projects
2. Identify patterns and insights
3. Reorganize if needed
4. Update this guide

## 🛠️ Tips & Tricks

- **Cmd/Ctrl + P**: Quick command palette
- **Cmd/Ctrl + O**: Quick switcher
- **Cmd/Ctrl + E**: Toggle edit/preview mode
- **[[]]**: Create links quickly
- Use **#tags** for categorization
- Leverage **YAML frontmatter** for metadata
