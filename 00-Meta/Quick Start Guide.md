# 🚀 Quick Start Guide

Welcome! This guide will get you up and running with your Obsidian vault in minutes.

## Step 1: Install Obsidian

1. Visit [obsidian.md](https://obsidian.md)
2. Download Obsidian for your platform
3. Install the application

## Step 2: Open This Vault

1. Launch Obsidian
2. Click "Open folder as vault"
3. Navigate to this repository folder
4. Click "Open"

## Step 3: First Look Around

### Main Interface
- **Left Sidebar**: File explorer and search
- **Center**: Your notes
- **Right Sidebar**: Backlinks and outline

### Key Areas to Visit
1. **[[Home]]** - Your starting point (you might be here!)
2. **[[Vault Guide]]** - Complete vault documentation
3. **[[01-Inbox/Inbox|Inbox]]** - Where to capture new ideas

## Step 4: Create Your First Note

### Option 1: Using Templates
1. Press `Cmd/Ctrl + N` to create a new note
2. Press `Cmd/Ctrl + P` to open command palette
3. Type "template" and select "Insert template"
4. Choose "Note Template"
5. Fill in the content

### Option 2: From Scratch
1. Press `Cmd/Ctrl + N`
2. Type your note name at the top
3. Start writing in Markdown
4. Link to other notes with `[[Note Name]]`

## Step 5: Explore Key Features

### Create Links
Type `[[` and start typing a note name:
```markdown
This connects to [[Vault Guide]]
```

### Add Tags
Use `#` to create tags:
```markdown
#important #project #todo
```

### Use Search
Press `Cmd/Ctrl + Shift + F` to search across all notes

### See Connections
Press `Cmd/Ctrl + G` to view your knowledge graph

## Essential Keyboard Shortcuts

### Must Know
- `Cmd/Ctrl + N` - New note
- `Cmd/Ctrl + O` - Quick switcher (find notes)
- `Cmd/Ctrl + P` - Command palette (all commands)
- `Cmd/Ctrl + E` - Toggle edit/preview mode

### Very Useful
- `Cmd/Ctrl + G` - Open graph view
- `Cmd/Ctrl + Shift + F` - Search all files
- `Cmd/Ctrl + Click` - Open link
- `Cmd/Ctrl + K` - Insert link

## Common Questions

### Where should I put new notes?
Start with the [[01-Inbox/Inbox|Inbox]]. Process and move them later.

### How many tags should I use?
3-5 tags per note is usually enough.

### Should I use folders or tags?
Both! Folders for broad categories, tags for themes.

### How do I link notes?
Type `[[` then the note name, then `]]`

### What's a MOC?
Map of Content - an index note linking to related notes.

### How often should I process my inbox?
Daily or weekly, whatever works for you.
