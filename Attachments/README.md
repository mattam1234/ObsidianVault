# Attachments Folder

This folder stores all attachments (images, PDFs, and other files) used in your notes.

## How It Works

When you drag and drop files into your notes or paste images, Obsidian automatically stores them here (configured in `.obsidian/app.json`).

## Organization

- Keep this folder clean by deleting unused attachments
- Consider creating subfolders for different types of media if needed
- Images can be embedded using: `![[image.png]]`

## Best Practices

- Use descriptive filenames
- Optimize images before adding them
- Regularly clean up unused files
- Consider external links for very large files
