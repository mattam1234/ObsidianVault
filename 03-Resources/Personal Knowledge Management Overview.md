# Personal Knowledge Management (PKM) Overview

## What is PKM?

Personal Knowledge Management (PKM) is a systematic approach to collecting, organizing, and utilizing information and knowledge for personal and professional development.

## Why PKM Matters

### Information Overload
- We consume more information than ever
- Most of it is forgotten quickly
- Need systems to retain and use knowledge

### Knowledge Work
- Modern work is increasingly knowledge-based
- Your knowledge is your competitive advantage
- Better organization = better thinking

### Continuous Learning
- Lifelong learning is essential
- Build on past insights
- Connect ideas across domains

## Core PKM Principles

### 1. **Capture**
- Save valuable information quickly
- Use inbox for temporary storage
- Don't worry about organization initially

### 2. **Organize**
- Structure information meaningfully
- Use folders, tags, and links
- Make retrieval easy

### 3. **Distill**
- Extract key insights
- Summarize in your own words
- Highlight important points

### 4. **Express**
- Use knowledge to create value
- Share insights with others
- Apply learning to projects

### 5. **Connect**
- Link related ideas
- Build knowledge networks
- Discover unexpected connections

## PKM Methodologies

### Zettelkasten
- Created by Niklas Luhmann
- Atomic notes (one idea per note)
- Heavy linking between notes
- Emergent organization
- Perfect for Obsidian

**Key Principles:**
- Each note is standalone
- Use unique identifiers
- Link notes liberally
- Let structure emerge

### PARA Method
Created by Tiago Forte

**Four Categories:**
- **Projects**: Active work with deadlines
- **Areas**: Ongoing responsibilities
- **Resources**: Topics of interest
- **Archives**: Inactive items

**Benefits:**
- Clear organizational structure
- Actionable focus
- Easy to maintain

### CODE Method
Also by Tiago Forte

**Four Steps:**
- **Capture**: Save valuable info
- **Organize**: Structure by actionability
- **Distill**: Extract essence
- **Express**: Create output

### Johnny Decimal
- Numerical organization system
- 10 categories, 10 areas each
- Precise filing location
- Good for structured minds

## Building Your PKM System

### Start Simple
1. Choose one method or combine elements
2. Start with basic structure
3. Add complexity as needed
4. Focus on consistency over perfection

### Essential Components

#### Capture System
- Quick inbox for ideas
- Mobile capture capability
- Integration with tools you use

#### Organization Structure
- Clear folder hierarchy
- Consistent naming
- Tag strategy
- Index pages

#### Review Process
- Daily: Process inbox
- Weekly: Organize and link
- Monthly: Reflect and refine
- Quarterly: System maintenance

### Tools Integration

#### Digital Tools
- **Obsidian**: Notes and linking
- **Readwise**: Article highlights
- **Pocket/Instapaper**: Read later
- **Zotero**: Research management

#### Physical Tools
- Notebooks for quick capture
- Index cards for brainstorming
- Whiteboard for visual thinking

## Best Practices

### Make It Personal
- Adapt systems to your needs
- Use language that makes sense to you
- Don't copy others blindly

### Progressive Enhancement
- Start simple
- Add features gradually
- Remove what doesn't work

### Regular Review
- Schedule review sessions
- Process captured items
- Maintain system health

### Focus on Value
- Not all information deserves capture
- Quality over quantity
- Capture what you'll actually use

## Common Pitfalls

### ❌ Over-Organization
- Spending more time organizing than learning
- Perfect is the enemy of done
- System should enable, not constrain

### ❌ Collection Without Processing
- Saving everything but reviewing nothing
- Hoarding instead of curating
- No value creation

### ❌ Tool Obsession
- Constantly switching tools
- Focusing on features over function
- The tool doesn't matter as much as the system

### ❌ No Output
- Only consuming and organizing
- Never creating or sharing
- PKM should enable creation

## Success Metrics

### Quantitative
- Consistent capture rate
- Regular review sessions
- Links created between notes
- Notes created vs. consumed

### Qualitative
- Easier to find information
- Better recall of ideas
- More connections between concepts
- Increased creative output
