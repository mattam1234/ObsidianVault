# ⌨️ Keyboard Shortcuts Reference

Quick reference for Obsidian keyboard shortcuts to boost productivity.

## Essential Shortcuts

### Navigation

| Action | Windows/Linux | macOS |
|--------|---------------|-------|
| Quick switcher | `Ctrl + O` | `Cmd + O` |
| Open command palette | `Ctrl + P` | `Cmd + P` |
| Search in all files | `Ctrl + Shift + F` | `Cmd + Shift + F` |
| Open graph view | `Ctrl + G` | `Cmd + G` |
| Navigate back | `Ctrl + Alt + ←` | `Cmd + Option + ←` |
| Navigate forward | `Ctrl + Alt + →` | `Cmd + Option + →` |

### File Operations

| Action | Windows/Linux | macOS |

## Pro Tips

### 1. Command Palette (`Ctrl/Cmd + P`)
- Search for any command
- Shows keyboard shortcuts
- Access all features

### 2. Quick Switcher (`Ctrl/Cmd + O`)
- Fast file navigation
- Type to search
- Recent files at top

### 3. Custom Hotkeys
- Go to Settings → Hotkeys
- Search for any command
- Assign custom shortcuts
- Export/import hotkey settings

## Common Workflows

### Creating Linked Notes
1. Type `[[` to create link
2. Start typing note name
3. Press `Enter` to create or link
4. `Ctrl/Cmd + Click` to open

### Quick Navigation
1. `Ctrl/Cmd + O` to open quick switcher
2. Type partial name
3. Use arrow keys to select
4. Press `Enter` to open

### Search and Replace
1. `Ctrl/Cmd + Shift + F` for global search
2. Click "Replace" button
3. Enter replacement text
4. Replace individually or all

## Customization

### Setting Custom Shortcuts
1. Open Settings (`Ctrl/Cmd + ,`)
2. Go to "Hotkeys" tab
3. Search for command
4. Click to set new shortcut
5. Avoid conflicts with system shortcuts

### Recommended Custom Shortcuts
- Set daily note shortcut
- Template insertion shortcut
- Toggle reading mode
- Quick capture to inbox
