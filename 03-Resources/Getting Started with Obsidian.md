# Getting Started with Obsidian

## What is Obsidian?

Obsidian is a powerful knowledge base that works on top of a local folder of plain text Markdown files. It's designed to help you organize your thoughts, ideas, and knowledge in a way that mirrors how your brain works - through connections.

## Key Features

### 1. **Markdown-Based**
- All notes are plain text
- Future-proof and portable
- Works with any text editor
- Version control friendly

### 2. **Linking**
- Create bidirectional links between notes
- Build a web of knowledge
- See connections in graph view
- Backlinks show where notes are referenced

### 3. **Local-First**
- Your data stays on your computer
- Complete privacy and control
- No cloud dependency (optional sync available)
- Fast and reliable

### 4. **Extensible**
- Community plugins
- Custom CSS themes
- Templates and hotkeys
- Flexible workflow

## Basic Workflow

1. **Create Notes**: Press `Cmd/Ctrl + N`
2. **Link Notes**: Use `[[Note Name]]` syntax
3. **Tag Notes**: Add `#tags` for organization
4. **Search**: Press `Cmd/Ctrl + O` for quick search
5. **Navigate**: Use backlinks and graph view

## Best Practices

### Atomic Notes
- Keep notes focused on one idea
- Makes linking easier
- Improves reusability

### Progressive Summarization
- Capture first, organize later
- Bold important points
- Highlight key insights
- Create summaries at the top

### Link Liberally
- Connect related ideas
- Don't worry about perfect organization
- Let the graph emerge naturally

## Common Use Cases

- **Personal Knowledge Management (PKM)**
- **Research and Study Notes**
- **Project Planning**
- **Daily Journaling**
- **Meeting Notes**
- **Book and Article Summaries**
- **Creative Writing**

| Action | Shortcut |
|--------|----------|

| Create new note | `Cmd/Ctrl + N` |
| Search | `Cmd/Ctrl + Shift + F` |

| Open graph view | `Cmd/Ctrl + G` |
